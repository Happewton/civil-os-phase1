## 19. Security Architecture

### 19.1 Threat Model

| Threat | Vector | Mitigation |
|--------|--------|------------|
| Unauthorized design modification | Compromised user account | MFA + RBAC + approval gates |
| Data exfiltration | Insider threat | Field-level encryption, audit logs, DLP |
| Calculation tampering | Malicious agent override | Calculation engine isolation, result signing |
| Prompt injection | Untrusted document ingestion | Input sanitization, sandboxed parsing |
| Supply chain | Compromised dependency | SBOM, dependency scanning, pinned versions |

### 19.2 Authentication & Authorization

```

│   Identity      │────→│   OAuth 2.0     │────→│   RBAC Engine   │
```

### 19.3 Role-Based Access Control

| Role | Project Read | Project Write | Task Execute | Task Approve | Admin |
|------|-------------|---------------|--------------|--------------|-------|
| Project Director | ✓ | ✓ | ✓ | ✓ | — |
| Discipline Engineer | ✓ | — | ✓ | ✓ (own) | — |
| Independent Checker | ✓ | — | — | ✓ | — |
| Construction Manager | ✓ | — | ✓ | — | — |
| Client/Sponsor | ✓ | — | — | ✓ (final) | — |
| System Admin | ✓ | — | — | — | ✓ |

### 19.4 Data Classification

| Class | Examples | Storage | Encryption |
|-------|----------|---------|------------|
| **Public** | Published standards, open GIS data | S3 standard | SSE-S3 |
| **Internal** | Project metadata, non-sensitive reports | PostgreSQL | TLS in transit |
| **Confidential** | Design calculations, cost data | PostgreSQL + application | AES-256 at rest, TLS |
| **Restricted** | Seismic hazard assessments, vulnerability data | Dedicated encrypted volume | AES-256-GCM, field-level |

### 19.5 API Security

- All API endpoints require Bearer token (JWT)
- Rate limiting: 100 req/min per user, 1000 req/min per service account
- Request signing for MCP server-to-server communication
- CORS: whitelist-only, no wildcards in production

## 25. Error Handling & Resilience

### 25.1 Error Taxonomy

| Code | HTTP | Description | Retryable |
|------|------|-------------|-----------|
| `VALIDATION_ERROR` | 400 | Input failed Pydantic validation | No |
| `ASSEMBLY_ERROR` | 422 | ECP assembly rule violation | No |
| `STATE_MACHINE_ERROR` | 409 | Invalid state transition | No |
| `GATE_BLOCKED` | 403 | Confidence gate blocked task | No |
| `NOT_FOUND` | 404 | Entity does not exist | No |
| `CALCULATION_ERROR` | 500 | Deterministic engine failure | Yes |
| `TIMEOUT` | 504 | External service timeout | Yes |
| `RATE_LIMITED` | 429 | Too many requests | Yes (with backoff) |

### 25.2 Retry Policy

| Service | Max Retries | Backoff | Circuit Breaker |
|---------|-------------|---------|-----------------|
| External GIS APIs | 3 | Exponential (1s, 2s, 4s) | 5 errors in 60s |
| Calculation engines | 2 | Linear (2s, 4s) | 3 errors in 30s |
| Database | 3 | Exponential | Never (critical path) |

### 25.3 Fallback Strategies

| Primary | Fallback | Degraded Behavior |
|---------|----------|-------------------|
| Real-time DEM | Cached DEM | Lower resolution |
| Live weather API | Historical averages | Less accurate loads |
| Full FEA | Simplified hand calc | Conservative results |
| Neo4j graph | PostgreSQL relations | Slower queries |
