CIVIL-OS
Engineering Context Engine — live demo

Stop design work resting on unverified assumptions.

CIVIL-OS gives every engineering input a provenance and a confidence level (A measured → E unverified), assembles that evidence into a versioned Engineering Context Packet, and refuses to start a task that depends on a level E assumption — unless a named engineer signs a waiver.

Safety-critical work is different: a waiver is never accepted, no matter who signs it.

This page is a faithful JavaScript port of the CIVIL-OS Phase 1 engine (civil_os/) — same ECP assembly rules, same content-hash versioning, same §7.3 gate. It runs entirely in your browser with no backend, so state is not shared or persisted.

The real package — Pydantic schemas, pytest suite, FastAPI service and MCP server — is at github.com/Happewton/civil-os-phase1. Run python demo.py or uvicorn app.api:app there.
