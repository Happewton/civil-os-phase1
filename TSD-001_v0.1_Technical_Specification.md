## 1. Executive Summary

CIVIL-OS is a **Civil Engineering Project Intelligence and Execution System** that acts as an engineering orchestrator, analyst, designer, checker, planner, documenter, and decision-support system for civil engineering projects across their entire lifecycle.

The system does **not** attempt to be an unverified autonomous professional engineer. Instead, it structures every engineering activity as a **traceable, auditable, machine-executable chain**:

```
Human Need → Project Definition → Site Evidence → Engineering Models → Design Decisions → Constructible Work Packages → Verified Construction → Operating Asset
```

Every output is produced through a chain of **evidence, calculations, standards, assumptions, uncertainties, and approvals** — not through language generation alone.

## 2. System Vision & Scope

### 2.1 Vision Statement

To create the definitive AI-powered operating system for civil engineering projects — where engineering intent flows through evidence, models, decisions, artifacts, and verification in a fully traceable, standards-compliant, human-governed workflow.

### 2.2 Scope Boundaries

| In Scope | Out of Scope (Phase 1–3) |
|----------|--------------------------| 
| Project lifecycle from social need through decommissioning | Fully autonomous design without human approval |
| Multi-disciplinary coordination (structural, geotechnical, hydraulic, environmental, etc.) | Real-time robotic construction execution |
| Site intelligence from satellite, drone, LiDAR, sensor data | Jurisdiction-specific permitting automation (varies by region) |
| Engineering calculation orchestration | Physical material testing |
| BIM/IFC model integration and clash detection | Legal contract negotiation |
| Cost estimation and schedule optimization | Real-time structural health monitoring hardware |
| Construction progress monitoring via imagery | Automatic procurement/contracting |
| Asset management and digital twin maintenance | — |
| Human approval gates and audit trails | — |

### 2.3 Guiding Principles

1. **Evidence-Based Engineering**: Every design decision must be traceable to evidence, standards, and calculations.
2. **Human-in-the-Loop**: Safety-critical decisions require human approval.
3. **Deterministic Calculations**: Mathematical analysis is performed by verified calculation engines, not LLMs.
4. **Graph-Based Knowledge**: Project knowledge is stored as a queryable, traversable graph.
5. **Confidence Classification**: Every data point carries a confidence level and provenance.
6. **Lifecycle Continuity**: Information flows seamlessly from planning through operation and decommissioning.
7. **ISO 19650 Alignment**: Information management follows ISO 19650 principles.

### 3.2 Component Definitions

| Layer | Component | Responsibility |
|-------|-----------|--------------| 
| **Interface** | Human Engineer | Requirements input, approval, judgment, accountability |
| **Orchestration** | Civil Project Orchestrator (CPO) | Context assembly, task routing, state management, workflow coordination |
| **Knowledge** | Knowledge Graph / RAG | Stores relationships, dependencies, engineering knowledge, project history |
| **Computation** | Engineering Calculation Engines | Deterministic mathematical analysis (structural, hydraulic, geotechnical, etc.) |
| **Integration** | MCP Tool Layer | Standardized interfaces to external tools, data sources, and enterprise systems |
| **Persistence** | Project Digital Twin & Data Layer | All project data: relational, document, blob, time-series, graph, vector |

### 3.3 Core Abstraction Chain

The central design pattern for every engineering activity:

```
ENGINEERING INTENT → EVIDENCE → MODEL → DECISION → ARTIFACT → VERIFICATION
```

| Step | Description | Example |
|------|-------------|---------| 
| **Intent** | What the project must achieve | Provide flood protection for 10,000 people |
| **Evidence** | Data collected to inform the solution | Rainfall records, terrain, land use, population, river geometry |
| **Model** | Analytical representations | Hydrology model, hydraulic simulation, cost model |
| **Decision** | Selected engineering strategy | Retention basin + drainage upgrade combination |
| **Artifact** | Deliverables produced | Design drawings, BIM model, specifications, cost estimate, schedule |
| **Verification** | Validation and checking | Code compliance check, independent review, construction inspection |
